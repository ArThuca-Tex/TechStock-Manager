# Relatório — TechStock Manager / Equipe Over

Arquivos principais:

- Relatorio_TechStock_Equipe_Over.pdf: versão final paginada, com 13 páginas.
- Relatorio_TechStock_Equipe_Over_Final.docx: versão editável final, com as dez figuras incorporadas.
- Relatorio_TechStock_Equipe_Over.html e .md: fontes alternativas do relatório.
- Recibo_Demonstracao.pdf: comprovante exportado pelo navegador.
- testes-execucao.txt: execução real dos 17 testes aprovados.
- imagens/: capturas originais e diagrama do modelo relacional.

A capa identifica a equipe Over e Arthur, Dimitri Santos, Enzo Frugeri, Maria Julia, Matheus Ribeiro e Vitor Ribeiro. Não foram inventados nomes de instituição, disciplina ou professor. Esses dados podem ser acrescentados no Word, se a atividade exigir.

As capturas foram obtidas em banco SQLite isolado para demonstração. Elas não alteraram o arquivo techstock.db do usuário. A captura de impressão aplica o CSS print, e o PDF do recibo foi produzido pelo Chrome. O relatório diferencia o SQLite validado do backend SQL Server ainda sem validação em servidor real.

O arquivo DOCX sem o sufixo Final foi uma versão intermediária que estava aberta no Word durante a geração. Para revisão e entrega, utilize a versão Final.

As fontes e os scripts de geração ficam em _tools. A pasta _work contém somente arquivos temporários e perfil de navegador da captura; não deve ser publicada.
